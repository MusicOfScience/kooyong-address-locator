# Modelling Assumptions

- Poll recency uses exponential decay with default half-life 14 days.
- Poll sample weighting uses square-root(sample size).
- House effect is applied as additive adjustment to primary vote.
- Monte Carlo uses normal error with configurable sigma (default 1.8pp).
- Preference flows are user-adjustable in UI.
- Scenario mode is explanatory, not deterministic.
